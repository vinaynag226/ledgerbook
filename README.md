# LedgerBook

Race-day command app for tracking Claude, Gemini and ChatGPT racing tips: alerts, agreement highlighting, results, bankroll and engine stats.

Live app: https://vinaynag226.github.io/ledgerbook/

Install on a phone: open the link in Chrome › ⋮ › Add to Home screen › Install.

No race, bet or bankroll data is stored in this repository. Data lives on the phone and, if sync is set up, in your own Firebase project behind your login.
